# Prettybel Portfolio

This is the GitHub-ready, flat-file version of the Prettybel portfolio.

## Upload to GitHub
Upload the files in this folder to the **root of the Prettybel repository**. Do not upload this ZIP as the website itself. GitHub will store a ZIP as a single file and will not unpack it for GitHub Pages.

## Edit later
- `projects.json` — project names, descriptions, screenshots, official links and proof links.
- `*.jpg` — replace an image with a new file using the same filename, or update the filename in `projects.json`.
- `style.css` — visual styling.
- `main.js` — dark/light mode, project loading and scroll interactions.
- `index.html` — page structure/content outside the project data.

All project screenshots are kept at the repository root in this version so Android/GitHub uploads do not require preserving nested folders.
